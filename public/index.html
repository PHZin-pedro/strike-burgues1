No GitHub Pages, o site é estático. Por isso esta versão salva automaticamente estoque, produtos e histórico no armazenamento do navegador. Fechar e abrir o mesmo link no mesmo celular/computador mantém os dados.

Para compartilhar o mesmo estoque/histórico entre vários celulares, é preciso ligar o GitHub Pages a um banco/servidor online. O modo local continua funcionando sem isso.

Impressora

Com Node rodando na rede, a impressão ESC/POS vai direto para a impressora Wi‑Fi/Ethernet. Se a conexão falhar, o botão de impressão pelo navegador aparece como plano B.

Bluetooth/USB direto no celular normalmente precisa de uma ponte Android; impressora de rede é a opção mais simples.
